# GuepardOS Welcome

Aplicación de bienvenida de GuepardOS escrita en Rust y GTK.

GuepardOS Welcome ayuda a revisar el estado inicial del sistema, instalar aplicaciones recomendadas mediante una lista cerrada de paquetes, abrir ajustes útiles de KDE Plasma y seguir una lista local de primeros pasos.

## Compilación

```sh
meson setup build
meson compile -C build
```
